- `@/components/erp/data-table` — props type `DataTableProps<Row>`:
  ```ts
  export type Column<Row> = { key: string; label: string; sortable?: boolean; className?: string; render?: (row: Row) => ReactNode };
  export type Paginated<Row> = { data: Row[]; current_page: number; last_page: number; per_page: number; total: number; from: number | null; to: number | null; links: { url: string | null; label: string; active: boolean }[] };
  export type DataTableProps<Row extends { id: number }> = {
    columns: Column<Row>[]; rows: Paginated<Row>; routeUrl: string;      // routeUrl = index URL (e.g. index.url())

    rowActions?: (row: Row) => ReactNode; toolbar?: ReactNode;              // toolbar renders left of the search box (filter selects)

  ```

**Controller** `app/Http/Controllers/<Area>/<Model>Controller.php` — template (replace `<…>`):
```php
<?php

namespace App\Http\Controllers\<Area>;

use App\Exports\TableExport;
use App\Http\Controllers\Controller;
use App\Http\Requests\<Area>\Store<Model>Request;
use App\Http\Requests\<Area>\Update<Model>Request;
use App\Models\<Model>;
use App\Support\TableQuery;
use Illuminate\Database\QueryException;
use Illuminate\Http\RedirectResponse;
use Illuminate\Http\Request;
use Illuminate\Routing\Attributes\Controllers\Middleware;
use Inertia\Inertia;
use Inertia\Response;
use Symfony\Component\HttpFoundation\BinaryFileResponse;

class <Model>Controller extends Controller
{
    #[Middleware('permission:<module>.<plural-kebab>.view')]
    public function index(Request $request): Response
    {
        $rows = TableQuery::apply(<Model>::query()<with()>, $request, [<searchable>], [<sortable>], '<defaultSort>', '<defaultDir>');

        return Inertia::render('<area>/<plural-kebab>/index', [
            'rows' => $rows,
            'filters' => $request->only(['search', 'sort', 'dir', 'per_page'<, custom filters>]),
        ]);
    }

    #[Middleware('permission:<module>.<plural-kebab>.create')]
    public function create(): Response
    {
        return Inertia::render('<area>/<plural-kebab>/form', [<form options>]);
    }

    #[Middleware('permission:<module>.<plural-kebab>.create')]
    public function store(Store<Model>Request $request): RedirectResponse
    {
        <Model>::create($request->validated());

        return redirect()->route('<area>.<plural-kebab>.index')->with('success', '<Singular> creado');
    }

    #[Middleware('permission:<module>.<plural-kebab>.update')]
    public function edit(<Model> $<model>): Response
    {
        return Inertia::render('<area>/<plural-kebab>/form', ['<model>' => $<model>, <form options>]);
    }

    #[Middleware('permission:<module>.<plural-kebab>.update')]
    public function update(Update<Model>Request $request, <Model> $<model>): RedirectResponse
    {
        $<model>->update($request->validated());

        return redirect()->route('<area>.<plural-kebab>.index')->with('success', '<Singular> actualizado');
    }

    #[Middleware('permission:<module>.<plural-kebab>.delete')]
    public function destroy(<Model> $<model>): RedirectResponse
    {
        try {
            $<model>->delete();
        } catch (QueryException $e) {
            if ($e->getCode() === '23503') {
                return back()->with('error', 'No se puede eliminar: el registro está en uso');
            }
            throw $e;
        }

        return redirect()->route('<area>.<plural-kebab>.index')->with('success', '<Singular> eliminado');
    }

    #[Middleware('permission:<module>.<plural-kebab>.export')]
    public function export(Request $request): BinaryFileResponse
    {
        $query = TableQuery::applyFilters(<Model>::query()<with()>, $request, [<searchable>], [<sortable>], '<defaultSort>', '<defaultDir>');

        return TableExport::fromQuery($query, '<plural-kebab>', [<export columns: 'Heading' => 'accessor'>], $request->string('format', 'xlsx')->toString());
    }
}
```

## Review Focus

Inputs the spec implies but which no single feature screen tests; each line names the owning task and the test added there.

1. **A Google account from the right domain whose user row exists but was deactivated after login** must be logged out on the next request, not just blocked at login → Task 4 `EnsureUserIsActive` test `inactive user is logged out on next request`.
2. **A super-admin trying to remove their own `super-admin` role or deactivate themselves** must be refused (otherwise support can lock itself out) → Task 9 tests `super admin cannot remove own super-admin role`, `user cannot deactivate self`.
3. **An exchange rate fetched for a date that already has a manual rate** must not overwrite the manual value (admin corrections win) → Task 13 test `scheduled fetch does not overwrite an existing manual rate`.
4. **An import file whose header row is missing or renamed** must be rejected at preview with a clear message, not create a batch of all-invalid rows → Task 24 test `preview rejects a file with missing required columns`.
5. **RNC/cédula with separators and spaces ("1-01-85004-3", "001-1391820-5")** must validate and be stored normalised (digits only) → Task 12 tests `rnc with dashes is normalised` / `cedula with dashes is normalised`, and Task 19 test `client tax id is stored normalised`.

```php
<?php

namespace App\Http\Middleware;

use Closure;
use Illuminate\Http\Request;
use Illuminate\Support\Facades\Auth;
use Symfony\Component\HttpFoundation\Response;

class EnsureUserIsActive
{
    public function handle(Request $request, Closure $next): Response
    {
        $user = $request->user();

        if ($user !== null && ! $user->is_active) {
            Auth::guard('web')->logout();
            $request->session()->invalidate();
            $request->session()->regenerateToken();

            return redirect()->route('login')->with('error', 'Tu cuenta está desactivada. Contacta a un administrador.');
        }

        return $next($request);
    }
}
```

```php
    {
        app(PermissionRegistrar::class)->forgetCachedPermissions();

        $roles = [];
        $newRoles = [];
        foreach (array_keys(PermissionCatalog::ROLES) as $name) {
            $role = Role::firstOrCreate(['name' => $name, 'guard_name' => 'web']);
            $roles[$name] = $role;
            if ($role->wasRecentlyCreated) {
                $newRoles[] = $name;
            }

                if ($permission->wasRecentlyCreated || in_array($roleName, $newRoles, true)) {
                    $roles[$roleName]->givePermissionTo($permission);
                }
            }
        }

        app(PermissionRegistrar::class)->forgetCachedPermissions();
```

```php
    /** Ensures every email in config('erp.super_admin_emails') exists as an active super-admin. Returns the number of users created. */
    public function handle(): int
    {
        $created = 0;

            if ($user === null) {

            if (! $user->hasRole(PermissionCatalog::SUPER_ADMIN)) {
                $user->assignRole(PermissionCatalog::SUPER_ADMIN);
            }
        }

        return $created;
    }
}
```

```php
<?php

namespace App\Actions\Auth;

use App\Actions\Admin\SyncSuperAdmins;
use App\Exceptions\LoginRejectedException;
use App\Models\User;
use Illuminate\Support\Facades\Auth;
use Laravel\Socialite\Contracts\User as GoogleUser;

class LoginWithGoogle
{
    public function __construct(private readonly SyncSuperAdmins $syncSuperAdmins) {}

    public function handle(GoogleUser $googleUser): User
    {
        $raw = $googleUser->getRaw();
        $email = strtolower(trim((string) $googleUser->getEmail()));
        $domain = (string) config('erp.google_workspace_domain');
        $isSupport = in_array($email, config('erp.super_admin_emails', []), true);

        if (($raw['email_verified'] ?? false) !== true) {
            throw new LoginRejectedException('Google no ha verificado el correo de esta cuenta.', $email, 'unverified');
        }

        if (! $isSupport && ($domain === '' || ($raw['hd'] ?? null) !== $domain)) {
            throw new LoginRejectedException("Solo se permite iniciar sesión con una cuenta de Google Workspace de {$domain}.", $email, 'domain');
        }

        if ($isSupport) {
            $this->syncSuperAdmins->handle();
        }

        $user = User::query()->whereRaw('lower(email) = ?', [$email])->first();

        if ($user === null) {
            throw new LoginRejectedException('Tu cuenta no está registrada en el sistema. Pide a un administrador que te invite.', $email, 'not_invited');
        }

        if (! $user->is_active) {
            throw new LoginRejectedException('Tu cuenta está desactivada. Contacta a un administrador.', $email, 'inactive');
        }

        $user->forceFill([
            'google_id' => (string) $googleUser->getId(),
            'avatar_url' => $googleUser->getAvatar(),
            'last_login_at' => now(),
        ])->save();

        Auth::guard('web')->login($user, remember: true);

        return $user;
    }
}
```

```php
    public function redirect(): SymfonyRedirect
    {
        $params = ['prompt' => 'select_account'];
        if ($domain = config('erp.google_workspace_domain')) {

        return Socialite::driver('google')->with($params)->redirect();

    public function callback(Request $request, LoginWithGoogle $action): RedirectResponse
    {
        try {
            $googleUser = Socialite::driver('google')->user();
        } catch (Throwable) {
            return redirect()->route('login')->with('error', 'No se pudo completar el inicio de sesión con Google. Inténtalo de nuevo.');
```

```php
<?php

namespace App\Support;

use Illuminate\Contracts\Pagination\LengthAwarePaginator;
use Illuminate\Database\Eloquent\Builder;
use Illuminate\Http\Request;

final class TableQuery
{
    /** @param list<string> $searchable  @param list<string> $sortable */
    public static function applyFilters(Builder $query, Request $request, array $searchable, array $sortable, string $defaultSort = 'id', string $defaultDir = 'desc'): Builder
    {
        $search = trim((string) $request->query('search', ''));
        if ($search !== '' && $searchable !== []) {
            $query->where(function (Builder $q) use ($search, $searchable): void {
                foreach ($searchable as $column) {
                    $q->orWhere($column, 'ILIKE', '%'.str_replace(['%', '_'], ['\%', '\_'], $search).'%');
                }
            });
        }

        $sort = (string) $request->query('sort', $defaultSort);
        $dir = strtolower((string) $request->query('dir', $defaultDir)) === 'asc' ? 'asc' : 'desc';
        if (! in_array($sort, $sortable, true)) {
            $sort = $defaultSort;
        }

        return $query->orderBy($sort, $dir)->orderBy($query->getModel()->getQualifiedKeyName(), 'desc');
    }

    public static function apply(Builder $query, Request $request, array $searchable, array $sortable, string $defaultSort = 'id', string $defaultDir = 'desc'): LengthAwarePaginator
    {
        $perPage = (int) $request->query('per_page', 15);
        $perPage = in_array($perPage, [15, 25, 50, 100], true) ? $perPage : 15;

        return self::applyFilters($query, $request, $searchable, $sortable, $defaultSort, $defaultDir)
            ->paginate($perPage)
            ->withQueryString();
    }
}
```

```php
<?php

namespace App\Actions\Admin;

use App\Models\User;
use App\Notifications\UserInvited;
use App\Support\PermissionCatalog;
use Illuminate\Auth\Access\AuthorizationException;
use Illuminate\Support\Facades\DB;

class SaveUser
{
    /** @param array{name: string, email: string, roles: list<string>, is_active?: bool} $data */
    public function handle(array $data, User $actor, ?User $user = null): User
    {
        $roles = array_values(array_unique($data['roles']));
        $wantsSuperAdmin = in_array(PermissionCatalog::SUPER_ADMIN, $roles, true);
        $isActive = $data['is_active'] ?? true;

        if ($wantsSuperAdmin && ! $actor->isSuperAdmin()) {
            throw new AuthorizationException('Solo un Super Admin puede asignar el rol Super Admin.');
        }
        if ($user !== null) {
            if ($user->isSuperAdmin() && ! $actor->isSuperAdmin()) {
                throw new AuthorizationException('Solo un Super Admin puede editar a otro Super Admin.');
            }
            if ($user->is($actor) && $user->isSuperAdmin() && ! $wantsSuperAdmin) {
                throw new AuthorizationException('No puedes quitarte tu propio rol de Super Admin.');
            }
            if ($user->is($actor) && ! $isActive) {
                throw new AuthorizationException('No puedes desactivar tu propia cuenta.');
            }
            if ($user->is_active !== $isActive && ! $actor->can('admin.users.deactivate')) {
                throw new AuthorizationException('No tienes permiso para activar o desactivar usuarios.');
            }
        }

        return DB::transaction(function () use ($data, $roles, $isActive, $user): User {
            $isNew = $user === null;
            $user ??= new User;
            $user->fill(['name' => $data['name'], 'email' => $data['email'], 'is_active' => $isActive])->save();
            $user->syncRoles($roles);
            if ($isNew) {
                $user->notify(new UserInvited);
            }

            return $user;
        });
    }
}
```

```php
{
    $actor = $request->user();
    abort_if($user->is($actor), 403, 'No puedes entrar como tú mismo.');
    abort_if(! $user->is_active, 403, 'El usuario está desactivado.');
    abort_if($user->isSuperAdmin(), 403, 'No se puede entrar como otro Super Admin.');

    $request->session()->put('impersonator_id', $actor->id);
    Auth::guard('web')->login($user);
    $request->session()->regenerate();

    return redirect()->route('dashboard')->with('success', "Ahora estás viendo el sistema como {$user->name}");
}

public function stop(Request $request): RedirectResponse
{
    $impersonatorId = $request->session()->get('impersonator_id');
    if (! $impersonatorId) {
        return redirect()->route('dashboard');
    }
    $impersonator = User::query()->findOrFail($impersonatorId);
    $impersonated = $request->user();
    $request->session()->forget('impersonator_id');
    activity('auth')->causedBy($impersonator)->performedOn($impersonated)->event('impersonation_stopped')->log("Salió del modo de suplantación de {$impersonated->name}");

    $request->session()->regenerate();
```

```php
<?php

declare(strict_types=1);

namespace App\Support\Money;

use Brick\Math\BigDecimal;
use Brick\Math\RoundingMode;

final class Decimal
{
    public const MONEY = 2;

    public const QTY = 4;

    public const RATE = 6;

    public static function of(string|int|BigDecimal $value): BigDecimal
    {
        return $value instanceof BigDecimal ? $value : BigDecimal::of($value);
    }

    public static function scale(string|int|BigDecimal $value, int $scale): string
    {
        return (string) self::of($value)->toScale($scale, RoundingMode::HALF_UP);
    }

    public static function money(string|int|BigDecimal $value): string
    {
        return self::scale($value, self::MONEY);
    }

    public static function qty(string|int|BigDecimal $value): string
    {
        return self::scale($value, self::QTY);
    }

    public static function rate(string|int|BigDecimal $value): string
    {
        return self::scale($value, self::RATE);
    }

    public static function mul(string|BigDecimal $a, string|BigDecimal $b, int $scale): string
    {
        return self::scale(self::of($a)->multipliedBy(self::of($b)), $scale);
    }

    public static function div(string|BigDecimal $a, string|BigDecimal $b, int $scale): string
    {
        return (string) self::of($a)->dividedBy(self::of($b), $scale, RoundingMode::HALF_UP);
    }

    public static function percent(string|BigDecimal $base, string|BigDecimal $pct, int $scale = self::MONEY): string
    {
        return (string) self::of($base)->multipliedBy(self::of($pct))->dividedBy(100, $scale, RoundingMode::HALF_UP);
    }

    /** @param iterable<string|int|BigDecimal> $values */
    public static function sum(iterable $values, int $scale = self::MONEY): string
    {
        $total = BigDecimal::zero();
        foreach ($values as $v) {
            $total = $total->plus(self::of($v));
        }

        return self::scale($total, $scale);
    }

    public static function isZero(string|BigDecimal $value): bool
    {
        return self::of($value)->isZero();
    }

    public static function cmp(string|BigDecimal $a, string|BigDecimal $b): int
    {
        return self::of($a)->compareTo(self::of($b));
    }
}
```

```php
<?php

namespace App\Support;

final class FiscalId
{
    private const RNC_WEIGHTS = [7, 9, 8, 6, 5, 4, 3, 2];

    public static function normalize(string $value): string
    {
        return preg_replace('/\D+/', '', $value) ?? '';
    }

    public static function rncCheckDigit(string $firstEight): int
    {
        $sum = 0;
        foreach (self::RNC_WEIGHTS as $i => $w) {
            $sum += $w * (int) $firstEight[$i];
        }

        return (10 - ($sum % 11)) % 9 + 1;
    }

    public static function isValidRnc(string $value): bool
    {
        $n = self::normalize($value);
        if (strlen($n) !== 9 || strlen(preg_replace('/\D/', '', $value) ?? '') !== strlen(preg_replace('/[\s-]/', '', $value) ?? '')) {
            return false;
        }

        return self::rncCheckDigit(substr($n, 0, 8)) === (int) $n[8];
    }

    public static function isValidCedula(string $value): bool
    {
        $n = self::normalize($value);
        if (strlen($n) !== 11 || strlen(preg_replace('/\D/', '', $value) ?? '') !== strlen(preg_replace('/[\s-]/', '', $value) ?? '')) {
            return false;
        }

        return self::luhnChecksum($n) === 0;
    }

    /** Luhn: from the rightmost digit, double every second digit, subtract 9 when > 9, sum; valid when sum mod 10 == 0. */
    private static function luhnChecksum(string $digits): int
    {
        $sum = 0;
        $double = false;
        for ($i = strlen($digits) - 1; $i >= 0; $i--) {
            $d = (int) $digits[$i];
            if ($double) {
                $d *= 2;
                if ($d > 9) {
                    $d -= 9;
                }
            }
            $sum += $d;
            $double = ! $double;
        }

        return $sum % 10;
    }

    public static function format(string $value): string
    {
        $n = self::normalize($value);

        return match (strlen($n)) {
            9 => substr($n, 0, 1).'-'.substr($n, 1, 2).'-'.substr($n, 3, 5).'-'.substr($n, 8, 1),
            11 => substr($n, 0, 3).'-'.substr($n, 3, 7).'-'.substr($n, 10, 1),
            default => $n,
        };
    }
}
```

```php
public function name(): string { return 'http_json'; }

public function fetch(Currency $currency, CarbonImmutable $date): ?FetchedRate
{
    $url = (string) $this->settings->get('exchange_rates.http_json.url', '');
    $path = (string) $this->settings->get('exchange_rates.http_json.json_path', '');
    if ($url === '' || $path === '') {
        throw new RuntimeException('La fuente externa no está configurada (URL y ruta JSON).');
    }
    $url = str_replace(['{currency}', '{date}'], [$currency->code, $date->format('Y-m-d')], $url);
    $json = Http::timeout(15)->acceptJson()->get($url)->throw()->json();
    $value = data_get($json, $path);
    if (! is_numeric($value)) {
        throw new RuntimeException("La respuesta no contiene una tasa numérica en la ruta '{$path}'.");
    }

    return new FetchedRate(Decimal::rate((string) $value), is_array($json) ? $json : []);
}
```

`ExchangeRateService` (constructor `Settings $settings`):
```php
public function source(): ExchangeRateSource
{
    return match ($this->settings->get('exchange_rates.source', 'manual')) {
        'http_json' => app(HttpJsonExchangeRateSource::class),
        default => app(ManualExchangeRateSource::class),
    };
}

public function rateFor(Currency|string $currency, CarbonInterface $date): ?ExchangeRate
{
    $currency = $currency instanceof Currency ? $currency : Currency::query()->where('code', $currency)->firstOrFail();

    return ExchangeRate::query()->where('currency_id', $currency->id)->whereDate('rate_date', '<=', $date->toDateString())->orderByDesc('rate_date')->first();
}

public function convertToBase(string $amount, Currency|string $currency, CarbonInterface $date): string
{
    $currency = $currency instanceof Currency ? $currency : Currency::query()->where('code', $currency)->firstOrFail();
    if ($currency->is_base) {
        return Decimal::money($amount);
    }
    $rate = $this->rateFor($currency, $date) ?? throw new MissingExchangeRateException("No hay tasa de cambio registrada para {$currency->code} en {$date->format('d/m/Y')} ni fechas anteriores.");

    return Decimal::mul($amount, $rate->rate, Decimal::MONEY);
}

/** @return list<ExchangeRate> */
public function fetchToday(): array
{
    $today = CarbonImmutable::today();
    $source = $this->source();
    $stored = [];
    foreach (Currency::query()->active()->where('is_base', false)->get() as $currency) {
        if (ExchangeRate::query()->where('currency_id', $currency->id)->whereDate('rate_date', $today->toDateString())->exists()) {
            continue; // never overwrite a rate already registered for today (manual corrections win)
        }
        $fetched = $source->fetch($currency, $today);
        if ($fetched === null) {
            continue;
        }
        $stored[] = ExchangeRate::create(['currency_id' => $currency->id, 'rate_date' => $today->toDateString(), 'rate' => $fetched->rate, 'source' => $source->name(), 'fetched_at' => now(), 'created_by' => null, 'notes' => null]);
    }
    $this->settings->set('exchange_rates.last_fetch_error', null);

    return $stored;
}
```

`ImportService::preview` algorithm:
1. Store the file: `$path = $file->store('imports/'.now()->format('Y/m'), 'local')`.
2. `$sheet = Excel::toCollection(null, $file)->first()`; if null/empty → `ValidationException::withMessages(['file' => 'El archivo está vacío.'])`. Header = first row; normalise each header with `Str::slug((string) $h, '_')`; build `$columnsByKey` from `importer->columns()` where each label normalised the same way maps to its `key`. Required columns missing → `ValidationException::withMessages(['file' => 'Faltan columnas obligatorias: '.implode(', ', $labels)])`.
3. Rows: skip rows where every cell is null/''. Max 5000 data rows else `ValidationException` `El archivo supera el máximo de 5000 filas.` For each row build `$data[key] = trim((string) $cell)` or `null` when empty (numbers from PhpSpreadsheet come as int/float — cast with `(string)` first; for the clients importer money columns the string is then passed to `Decimal`).
4. Validate with `Validator::make($data, $importer->rules($data, $meta), $importer->messages())`; collect `errors()->toArray()` flattened to `['field' => 'message', ...]` (first message per field). In-file duplicates: `naturalKey($data)` seen before → add error `_row: 'Valor duplicado en el archivo (fila N)'`.
5. `action` = `findExisting($data) ? 'update' : 'create'` (only when valid). Insert rows in chunks of 500 (`ImportBatchRow::insert`). Create the batch with counts and `status previewed`; log `activity('imports')->causedBy($user)->performedOn($batch)->event('previewed')->log("Vista previa de importación de {$importer->label()}")`.
`ImportService::confirm`: `abort_if($batch->status !== previewed, 422)`; transaction; iterate valid rows ordered by `row_number` in chunks of 200, `persist()`, count created/updated; set `status confirmed`, `confirmed_at`, counts; activity event `confirmed` with properties counts. Rows of invalid lines are left untouched (user fixes the file and re-uploads).

```php
}
```
